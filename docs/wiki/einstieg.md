# Überblick

**Faire Schlafquote für Multiplayer-Server:** Wer nicht mitschlafen kann oder will, bremst die Nacht nicht mehr aus, und mit `/nosleep` hält man die Nacht fest, wenn man sie für eine Farm braucht.

| Auf einen Blick | |
|---|---|
| Server | Paper 26.3 (oder ein Fork wie Purpur), Java 25 |
| Benötigt | nichts - LuckPerms ist empfohlen, MRadmin optional |
| Sprachen | Deutsch, Englisch - jeder Spieler automatisch in der Sprache seines Minecraft-Clients |
| Status | stabil (1.x) |

## Was kann MRsleep?
- **Schlafquote mit Ausnahmen:** Bots, Cam-Accounts, Zuschauer und AFK-Spieler zählen nicht mit. Die Nacht wird übersprungen, sobald genug *echte* Spieler schlafen. → [Schlafquote mit Ausnahmen](schlafquote.md)
- **`/nosleep`:** Ein Spieler blockiert das Schlafen für eine oder mehrere Nächte - perfekt für Mob-Farmen oder Bauprojekte bei Nacht. → [/nosleep](nosleep.md)
- **Admin-Menü:** Alle Spieler als Köpfe mit Live-Status. Sperren, Cooldown aufheben oder Blockaden lösen geht per Klick. → [Admin-Menü](admin-menue.md)
- **Anzeige nach Wahl:** Fortschritt als Bossbar, Actionbar oder Titel, dazu Chat-Hinweise wie „Alex hat sich schlafen gelegt (1/2)“. → [Anzeige & Chat-Hinweise](anzeige.md)
- **Alles einstellbar:** eine `config.yml`, alle Texte in Sprachdateien, für jede Funktion eine eigene Permission. → [Konfiguration](konfiguration.md)
- **Discord-Logs** über einen Webhook und eine **Update-Prüfung**, die dich im Spiel informiert. → [Discord & Protokoll](discord.md)
